# English UI recognition data

`eng.traineddata` is the unmodified English LSTM model from
[tesseract-ocr/tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast)
commit `87416418657359cb625c412a48b6e1d6d41c29bd`.

SHA-256: `7d4322bd2a7749724879683fc3912cb542f19906c83bcc1a52132556427170b2`

The model is packaged locally as `tessdata/eng.traineddata`. Recognition never
sends client images or credentials to a remote service. The Apache 2.0 license
is in `packaging/licenses/Tesseract-Apache-2.0.txt`.
