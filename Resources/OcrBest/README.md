# Accurate English UI recognition data

`eng.traineddata` is the unmodified English LSTM model from
[tesseract-ocr/tessdata_best](https://github.com/tesseract-ocr/tessdata_best)
commit `e12c65a915945e4c28e237a9b52bc4a8f39a0cec`.

SHA-256: `8280aed0782fe27257a68ea10fe7ef324ca0f8d85bd2fd145d1c2b560bcb66ba`

The downloaded file's Git blob identity was checked against the GitHub content
API: `176dc3220de7db34d3b3aecbfa42043a6038348b` (15,400,601 bytes).

The model is packaged locally as `tessdata-best/eng.traineddata` for bounded
small-text recognition. It does not send images or credentials to a service.
The Apache 2.0 license is in `packaging/licenses/Tesseract-Apache-2.0.txt`.
